# GEMINI.md

Rules and execution constraints for Gemini and Antigravity agents in this repository.

## Operational Constraints

- **Strict Task Boundaries**: Execute ONLY what the user asks for. Never do unrequested extra work.
- **No Unsolicited Git Actions**: When requested to make code/documentation changes, ONLY make the changes. NEVER create git commits, merge branches, switch branches, or push unless explicitly commanded by the user.
- **Zero Assumptions**: Do not assume missing information or proceed with unstated assumptions.
- **Ask on Ambiguity**: If anything in the prompt is unclear or ambiguous, ask the user clarifying questions first.
